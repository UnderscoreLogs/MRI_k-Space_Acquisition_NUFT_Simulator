# MRI_k-Space_Acquisition_NUFT_Simulator

A C++ program that simulates MRI k-space acquisition and image reconstruction using Non-Uniform Discrete Fourier Transforms (NUDFT). The program enables the testing and comparison of different k-space sampling trajectories under varying acquisition conditions.

Features
Simulates MRI k-space acquisition
Reconstructs images using NUDFT
Supports multiple k-space sampling trajectories
Enables comparison of trajectories under different acquisition conditions
Provides image reconstruction and trajectory visualization

Requirements
The program requires external libraries, including OpenCV, to compile and run.

Depending on your system configuration, you may need to modify:

Library and include paths
File and directory paths
Compiler or build settings
